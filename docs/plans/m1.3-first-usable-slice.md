## Goal

A person opens CHRONOS and sees the Strata globe on its Nocturne stage. They can then:
- scrub or step from 3400 BCE to 2024 CE;
- select a polity and see it highlighted;
- read its card, with source, licence, evidence and QA flags;
- click any ground for a core sample of who is mapped there across time.

Overlaps are drawn deliberately. Loading uses the measured delivery approach (D-024), and every 1.2 guarantee still holds on the real UI build.

## Architecture of the slice

```
pipeline (0.3.0) ── bundle format 3 ──────────────────────────────────────────────┐
  geometry.<hash>.bin   positions f4 · triangles as per-part delta + zigzag varints │  .br / .gz precompressed,
                        · edge flags · overlap regions (own triangles + spans)      │  content-hashed, immutable
  bundle.json           catalogue, years, colours, coverage series, file manifest   │  revalidated
  catalog.<hash>.json   per-polity QA findings, overlaps per row, review notes      │  lazy, on first card
  relief/{z}/{x}/{y}.webp · basemap.<hash>.json (land, lakes, rivers)                │
                                                                                     ▼
apps/web: React 19 + Tailwind v4 shell ── stores (time, selection, sample, view) ── URL hash
          AtlasEngine (imperative): MapLibre globe and basemap; deck.gl territory and overlap layers
            with StrataExtension: exact year visibility, wall-clock dissolve (D-020), select/hover/dim, stripes
          loader worker (fetch with progress, varint decode, transfer) · core-sample worker (point query)
```

## Work packages and acceptance criteria

### WP1: Delivery (format 3, compression, loading path)
- **Pipeline.**
  - Triangle indices stored per part, relative to the part's first vertex, delta-coded, zigzag-mapped and written as LEB128 varints. Delta + zigzag was measured in spike 003; varints are chosen if they measure smaller in memory at equal or better brotli size (measured, then recorded in D-025).
  - Edge flags, one byte per vertex.
  - Content-hashed file names, and `.br` (quality 11) plus `.gz` precompressed copies written deterministically.
  - `bundle.json` lists every file with its sha256, raw size and encoded sizes.
- **Web.**
  - Dev and preview servers negotiate `Accept-Encoding` and serve the precompressed file with `Content-Encoding`.
  - A worker fetches with real progress (decoded bytes against the known size), decodes and transfers.
  - A "loading territories" state that ends only on the **first correct pick**, not on an engine signal.
- **Acceptance.**
  - Decode is lossless (test against the pipeline's triangles).
  - `make reproducible` stays byte-identical, including the compressed files.
  - Geometry over the wire ≤ 3 MiB with brotli.
  - First view at 117 CE interactive (first correct pick) within **1.5 s** locally on this M2.
  - A failed fetch shows an error with retry.

### WP2: Strata stage (Nocturne)
- **Basemap.**
  - Natural Earth 1:50m shaded relief as transparent hillshade tiles (z0–5, built in the pipeline).
  - Land, lakes and rivers.
  - Coastline line.
  - Graticule.
  - Atmosphere and space background.
- **Design system.** Strata tokens (design-direction.md) as Tailwind v4 `@theme`. Newsreader, IBM Plex Sans and IBM Plex Mono self-hosted (OFL), not fetched from a font CDN.
- **Interaction.** Globe ↔ flat toggle, `flyTo`, reduced motion (cuts).
- **Acceptance.**
  - 60 fps while scrubbing with the full stage.
  - Credits list Natural Earth.
  - No network requests other than our own origin.

### WP3: TimeEngine and timeline
- **TimeEngine.** One store: `t`, `playing`, `rate`, view window. Integer astronomical years. Exact steps of year / decade / century / millennium. Labels via one formatter with no year 0.
- **Timeline.**
  - An overview strip covering all of 3400 BCE–2024 CE, with a **record-density** histogram (polities mapped per year, computed from the bundle).
  - A zoomable detail track (wheel or pinch, drag to pan) with ticks that adapt: millennia → centuries → decades → years.
  - Play/pause and speed presets.
  - Keyboard: ←/→ one year, Shift ten years, Alt one hundred years, Space, Home/End.
- **Transitions.** Year changes cross-dissolve over **wall-clock time** (D-020), never over years. A dissolve never shows a polity in a year it is not valid once it has finished, and scrubbing or reduced motion cuts.
- **URL state.** `#t=…&c=lon,lat,zoom&p=…&s=lon,lat` reproduces the view.
- **Acceptance.**
  - Unit tests for stepping across 1 BCE/1 CE, tick generation at every zoom, formatting and URL round-trip.
  - 0% stale frames under the scrub protocol.

### WP4: Selection and highlighting
- **StrataExtension** (deck.gl `LayerExtension`): a per-vertex polity id against uniforms for the selected and hovered polity. Other polities are dimmed while one is selected.
- **Outline.** The selected polity gets a bone outline drawn from real (non-synthetic) edges only, year-filtered on the GPU.
- **No geometry re-upload** on hover or select.
- **Acceptance.**
  - Select and hover cause no attribute uploads (checked on the attribute manager).
  - Pick accuracy 343/343 with the extension active.
  - Heap stays below 400 MB.

### WP5: Overlapping territories
- **Pipeline.** Every pair of base rows whose polygons share interior while both are valid gives an overlap region: the intersection, with span `[max start, min end]`, its area (EPSG:6933) and its kind (*linked*, *sliver* or *unlinked*, same rule as QA-004). Each region is triangulated with the QA-013 check and stored as its own section. Triple overlaps are counted and reported.
- **Display.** Regions are drawn above the fills as diagonal stripes alternating the two polities' colours, so what shows no longer depends on draw order. Picking returns both polities.
- **Card and core sample** name the overlap, its area and its kind, with neutral wording: "both mapped here in Cliopatria; no relationship recorded".
- **Acceptance.**
  - 420 CE Kidarites × White Huns renders striped.
  - Reversing the fill draw order changes no pixel inside overlap regions (render test).
  - The overlap totals per checkpoint year match QA-004.

### WP6: Polity card
- **Identity.** Name; polity lifespan and the current row's years (BCE/CE).
- **Area.** Polygon area of the current row (EPSG:6933, *combined polygon area* for one polity), the area it shares with others in the current year, and the polity's area over time as a sparkline.
- **Wikidata.** As given by the source, with its own label; the verified correction if one exists; flags.
- **Quality and provenance.**
  - QA flags with their messages.
  - Review notes.
  - Evidence *interpreted (atlas)*; confidence *not stated by the source*.
  - Source and licence (CC BY 4.0), the Cliopatria row locator and the release id.
  - "How is this calculated?" opens the trace entry: method, parameters, input sha256.
- **Wording rules** (design-direction.md): *mapped*, never *ruled* or *controlled*; every aggregate states coverage.
- **Acceptance.**
  - Component tests on real catalogue entries: Roman Empire at 117, a corrected QID, a QA-009 polity.
  - No research-only source anywhere in the build (QA-012 still enforced).

### WP7: "Who is mapped here?" core sample (browser-side)
- **Worker.** A grid index over render parts; an exact point-in-polygon test on the float32 rings; near hits within 5 km by distance to edges in a local azimuthal-equidistant frame. Strata are merged exactly as the pipeline's `PointIndex` does; gaps and overlaps are computed the same way.
- **Panel.** A vertical core column (oldest at the bottom).
  - Exact strata solid; near hits dashed with "within ~N km"; gaps hatched *unmapped*; overlaps split the column.
  - The current year is marked.
  - Clicking a stratum selects the polity and moves time.
- **Acceptance.**
  - **Rome equals the pipeline's QA-010 result exactly**: 22 strata, names, years, exact/near, gaps `[476–499], [1944]`, overlaps. Distances agree within 1%.
  - The test points' expected polities are contained in the sample at their year.

### WP8: The two grid seams (spike 002 §7)
- Find the root cause with pixel evidence at high zoom: T-junctions between grid parts, float32 rounding, or MapLibre's tiling.
- Fix it in the pipeline if it is ours (for example, shared vertices on both sides of a grid edge). Otherwise document it.
- **Acceptance.** A render-agreement view at the seam shows no crack on our side, or a documented cause outside our code.

### WP9: Quality, compatibility, documentation
- **Benchmark protocol** runs against the app (`bench/run.mjs --engines app`): sweep, Europe, jumps, explore, endurance; 343 picks; heap and process footprints.
- **Render agreement** of the app's territory pass (neutral colouring) against the 1.2 binary path.
- **Safari.** A manual compatibility page (`/compat.html`) runs automatic checks and records manual observations to `docs/compat/`. It needs one manual run in Safari by you: no system setting changes, no automation.
- **Documentation.** Decisions D-025 onward, a spike/report 004, roadmap, README, credits page.

## Out of scope

- PostGIS and the API (1.4).
- Events, routes and journeys; label spines and gain/loss pulses (1.5–1.6).
- Lineage colour families, which need lineage data.

## Risks

| Risk | Mitigation |
|---|---|
| A custom deck.gl extension breaks picking or the globe projection | Built from `DataFilterExtension`'s pattern; the 343-point test runs on every change |
| Overlap regions are expensive to compute across all time | Vectorised STRtree candidate search with time filtering first; build time measured and reported |
| Brotli quality 11 slows `make data` | Quality and window are build parameters; build time recorded |
| Safari can't be automated | A recorded manual run; anything that run doesn't cover is stated |
